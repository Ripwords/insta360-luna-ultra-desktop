title: Connecting to the camera
description: Join the Luna Ultra's Wi-Fi network, connect from the app, and troubleshoot a failed session.

## Join the camera's Wi-Fi

The Luna Ultra exposes its own Wi-Fi network. Join it from your computer's
network settings before opening the app. The camera's default gateway is
`192.168.42.1`, which is the host the Connect screen pre-fills.

## Connect

Open the Connect screen and press Connect. The app remembers the host you used
between launches — it is persisted to `localStorage` under `luna-camera-host`,
so a camera on a non-default address does not need to be retyped every time.

## What is actually happening

The Luna Ultra exposes two services on its Wi-Fi network:

- **TCP control (port 6666)** — a UCD2-framed binary protocol used for the auth
  handshake, device info, and delete commands. A live control session is what
  unlocks the HTTP media index below.
- **HTTP (port 80)** — an autoindex-style listing of the camera's storage, plus
  `Range`-capable file downloads.

## Auto-reconnect

If the connection drops, the app retries on a backoff schedule of 1s, 2s, 5s,
10s, 15s, with the last delay repeating until it succeeds. It also retries
immediately whenever the OS reports the network came back (for example,
rejoining the camera's Wi-Fi after it was out of range).

## Troubleshooting

Camera control requires the desktop app — a browser cannot open a raw TCP
socket, so the web build shows a message saying so instead of a Connect button
that can't work.

If the gallery says "Nothing here" while the app is connected, that is a media-
index problem, not a live-view one: the HTTP media index returned a non-ok
response. The live viewfinder can be working fine at the same time.
